# 2025中国机器人大赛-机器人寻宝

## 机器人开发平台

芯片：STM32F407VET6
编译器：gcc_arm 2021.10
下载平台：openocd

## 工程文件说明

- .eide eide 工程配置文件夹
- .vscode vscode 工程配置文件夹
- build 编译文件输出目录文件夹
- Core STM32 核心驱动
- STM32F4xx_StdPeriph_Driver STM32F4 标准外设库
- BSP 传感器外设驱动文件
- System 单片机计时器、复位控制与检测文件
- Motion 机器人运动控制与动作文件
